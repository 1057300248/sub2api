## Integrated contracts

The complete upstream history is merged, including API-key concurrency, final deleted-key settlement semantics, received stream usage, model ownership and WebSocket authentication fixes. Conflict resolution keeps both Cline and TypeSafe, but TypeSafe remains excluded from ordinary static LLM catalogs and channel-monitor protocols.

Request-level custom JSON parameters survive Responses/Messages lowering for independent Cline and the existing official-host OpenAI/DeepSeek API-key compatibility path. Unknown vendor fields retain explicit zero/false and nested values. Protocol-owned Chat fields cannot be overwritten. Parameters are not persisted on accounts and no provider is hardcoded. The same source request remains reusable for the next account attempt. This does not make arbitrary gateways Cline or grant Free/Pass entitlements.

A bounded parser recognizes only the confirmed Cline/Vercel error wrapper carrying an inner 429 error with a structured rate-limit code or the observed team-limit signature. Normal content, tool/reasoning output and unrelated 502 errors do not trigger it. Scheduling sees 429 and disables same-account immediate retries; ops retains the original HTTP status and body. Existing legacy accounts receive account-local monotonic cooldowns, not an inferred pool-wide team block. Independent accounts retain credential/subject-scoped durable limits.
